# Docs index

Curated map of `docs/`. Reviewed monthly — when you add a document, list it here.

- `product/brief.md` — what we're thriving for (mission, goals, success criteria,
  constraints). **The coordinator bot reads this first.** Fill it from
  `templates/brief.md` at first boot.
- `product/` — specs, roadmap, user research.
- `decisions/` — ADRs (`0001-kebab-case.md`, numbered, never renumbered; supersede
  instead of editing).
- `meetings/` — dated meeting notes (`YYYY-MM-DD-<topic>.md`).
- `howto/` — operational playbooks: dev, deploy, tooling, recovery.
